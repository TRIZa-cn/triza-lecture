# TRIZ 创新构思法研讨班 · 讲义生产线

16 次课（1 学分 / 16 学时）的课件、讲稿与生成脚本。

## 目录

| 路径 | 内容 |
| --- | --- |
| `PPT/TRIZ_W1_矛盾15m.pptx` | 第 1 次课课件（基线，不再改） |
| `PPT/W2_16/` | 第 2–16 次课生成脚本与成品 |
| `PPT/W2_16/out/` | 15 份课件成品（每份 12 页，约 75 KB） |
| `PPT/TRIZa-Lecture-SKILL.md` | 讲义制作规范（字号、页数、讲稿、页脚） |
| `docs/` | git 策略、讲课风格档案、声音演播方案 |
| `style/` | 机器可读的风格规则 |

## 重建

```powershell
python PPT\W2_16\w_build.py          # 生成 15 份 pptx
python PPT\W2_16\w_fit.py PPT\W2_16\out   # 版式溢出检查
python PPT\W2_16\w_final.py          # 五项校验，输出一行 JSON
```

## 校验口径

- 每份 12 页
- 正文 ≥20pt（kicker 14 / 页脚 12 / 页码 12 / 封面署名 12 / 图内标签 14–18 豁免）
- 讲稿 3000–3500 字（约 15 分钟，235 字/分）
- 第 11 页含 TRIZa 练习与提交要求
- 页脚统一：`TRIZ 创新构思法实战研讨班  ·  第 N 次 Workshop`
