# TRIZa 讲义仓

本仓是**白名单仓**：默认忽略一切，只跟踪两类内容。

## 发布什么、不发布什么

| 类别 | 是否入库 | 路径 |
| --- | --- | --- |
| 最终演播版课件 | ✅ | `playablePPT/*.pptx` |
| 可复用的技能与插件骨架 | ✅ | `skills/`、`plugins/` |
| 课件源码、生成脚本 | ❌ | 留在本地工作盘 |
| 讲稿、导演指令、课程设计 | ❌ | 留在本地工作盘 |
| 录音、音频、训练包、PDF 文献 | ❌ | 留在本地工作盘 |

**为什么这样切。** 技能与插件是**给用户用的方法**，可以公开；讲稿与课程设计是**课程内容本身**，
以及作者的讲课风格，不对外发布。演播版是对外交付物，单独放行。

判断标准：这份东西是"教别人怎么做课"，还是"这门课具体怎么讲"？前者入库，后者不入库。

## 目录

| 路径 | 内容 |
| --- | --- |
| `playablePPT/*.pptx` | 最终演播版课件 |
| `skills/lecture-film-review/` | 七段结构审课清单（方法论，无课程实例） |
| `skills/pptx-shape-diagrams/` | 原生形状画图 + 配音同步动画 |
| `plugins/triza-lecture/` | 讲义生产线骨架：设计→讲稿→排版→配音→合成 |
| `.gitignore` | 白名单规则 |
| `LICENSE` | MIT |

## 怎么加一份演播版

```powershell
# 1. 自己把最终演播版拖进 playablePPT/
git add playablePPT/xxx_演播版.pptx
git commit -m "feat: 新增第 N 次课演播版"
git push
```

## 关于 plugins/triza-lecture

目前是**方法骨架**，不是可安装插件：没有安装清单、没有入口脚本、没有版本号。
等这条流水线在真实讲义上跑顺，再定它长成什么样。

## 一个提醒

`skills/lecture-film-review` 的结构取自夏晋宇《好课像大片：一门课，一个亿》的公开章目
（电子工业出版社，2024，ISBN 9787121478130）。**本仓没有该书正文**，
技能文件里的文献对照是独立整理的，不是该书的引用。引用前请自行核对。
