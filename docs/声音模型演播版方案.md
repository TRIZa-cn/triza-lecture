## 二、目标格式：与 en-US-AndrewNeural 完全一致

实测 `PPT/_voices/andrew.mp3` 的帧头：

```
容器      MP3 (MPEG-1 Layer III)
采样率    48 000 Hz
声道      单声道
码率      80 kbps CBR
帧长      1152 采样 = 24 ms
```

要产出的个人音轨必须落到同一规格，否则 PowerPoint 内嵌播放会出现变速或不同步：

| 参数 | 目标值 | 说明 |
| --- | --- | --- |
| 容器 | MP3 | 与参考音一致，兼容性最好 |
| 采样率 | 48 kHz | 不要 24 kHz，重采样会造成时长微漂 |
| 声道 | 单声道 | 立体声无意义且体积翻倍 |
| 码率 | 80 kbps CBR | 语音足够，CBR 避免 VBR 时长估算误差 |
| 响度 | −16 LUFS | 整段归一，避免逐页音量跳变 |
| 真峰 | ≤ −1.5 dBTP | 防削波 |
| 句间静音 | 120–200 ms | 太短像赶，太长像卡 |
| 页间静音 | 400 ms | 给翻页留呼吸 |

## 三、生产链路（8 步，可脚本化）

```
pptx notes
   │ ① 抽取：页号 → 文本（narration.json）
   ▼
分句（。！？；）→ 每句一条，去掉 markdown 标记
   │ ②
   ▼
模型合成 → 原始 wav（24k 或 32k，模型原生采样率）
   │ ③
   ▼
重采样 48 kHz / 单声道（ffmpeg -ar 48000 -ac 1）
   │ ④
   ▼
响度归一 −16 LUFS（ffmpeg loudnorm 两遍）
   │ ⑤
   ▼
编码 80 kbps CBR mp3（ffmpeg -b:a 80k -abr 0）
   │ ⑥
   ▼
时长表 durations.json（每页累计起点/时长）
   │ ⑦
   ▼
嵌入 pptx：每页一个 audio，自动播放，切页停
   │ ⑧
   ▼
启动器 + 同步日志
```

第 ③ 步是唯一依赖「你的模型」的环节；其余 7 步与音色无关，现在就能搭好并验证。

## 四、三条路线（按落地成本排序）

### 路线 A · 零样本克隆（推荐先试）

- 工具：CosyVoice2-0.5B / F5-TTS / GPT-SoVITS zero-shot
- 输入：**3–10 秒**干净参考音（你现在就有大量录音，切一段即可）
- 产出：30 分钟内可出第一版
- 代价：音色接近，韵律偏平，长句偶有吞字
- 适合：先把整条链路跑通，验证同步与启动器

### 路线 B · 微调（要「像」就走这条）

- 工具：GPT-SoVITS v2 / CosyVoice 微调
- 输入：**30 分钟–2 小时**切片语料（3–10 s 一段）+ 对应文本
- 产出：1–2 天（含训练）
- 代价：需要 GPU；切片与标注是主要工作量
- 适合：正式录播、对外发布

### 路线 C · 托管服务

- Azure Custom Neural Voice（需企业资质与授权审批）、Fish Audio 等
- 代价：数据外发、按量计费、审批周期
- 适合：不想维护本地环境

## 六、驱动全屏自动播放

### 两种驱动方式

**方式一 · 内嵌音频自动播放（推荐）**

- 每页插入该页音频，设「自动播放」「跨页播放：否」
- 幻灯片切换设为「单击之后 0 秒」并用排练计时记录每页停留
- 启动：`powerpnt.exe /S "第02次_....pptx"` 直接全屏放映

**方式二 · 外部时钟同步（兜底）**

- Python 读 `durations.json`，用 `win32com` 控制 `SlideShowWindow.View.Next()`
- 精度可到 ±100 ms，适合音频不嵌入、外放的场景

### 启动器

`启动_第02次演播.cmd`：

```
@echo off
powershell -NoProfile -ExecutionPolicy Bypass -File "%~dp0play_deck.ps1" -Deck "第02次_功能分析与系统建模_演播版.pptx" -Fullscreen
```

`play_deck.ps1` 职责：检查文件 → 记录开始时间 → 调 PowerPoint 全屏 → 放映结束写日志。

### 同步日志结构

```json
{
  "deck": "第02次_功能分析与系统建模_演播版.pptx",
  "started_at": "2026-11-01T20:15:03+08:00",
  "slide_count": 12,
  "pages": [
    {"slide": 1, "audio": "s01.mp3", "dur_ms": 41200, "planned_ms": 41200,
     "actual_ms": 41380, "drift_ms": 180}
  ],
  "max_abs_drift_ms": 180,
  "total_ms": 792400,
  "pass": true
}
```

判据：**每页 |drift| ≤ 200 ms**，总时长与讲稿估算（字数 ÷ 235 字/分）偏差 ≤ 5%。超限的页单独标红，保留人工翻页兜底。
